# Novelty kill-test (literature)

A candidate is "new_signal" only if a precise literature search fails to find it described.
1. Write 3+ queries with precise descriptors: variable + region name + period + kind of change, e.g.
   "root zone soil moisture decline Saiss plain Morocco 2000s", "rainy season onset shift northwest
   Morocco", "Atlas mountains snow depth trend MERRA-2". Also query the mechanism you suspect.
2. Read titles and abstracts returned. Classify each hit: describes the same signal / related /
   unrelated. Cite hits by title and year in your summary.
3. If the signal is described: outcome = known_phenomenon (still valuable: the harness rediscovered
   it blind, which validates the method). If only the broad phenomenon is known (e.g. regional
   warming) but not the specific feature you found (e.g. season, location, abruptness, decoupling),
   say exactly what part is new.
4. If no literature tool result was obtained (rate limit, network), the novelty check was NOT run.
   Say so; never assert novelty without it.
5. **Off-topic results are not novelty.** If the hits are about something else (politics, another region,
   another variable) or the tool says COVERAGE WEAK, the search failed; it did not show the signal is new.
6. **Documented by default.** Near-surface warming trends and more frequent heat extremes (T2M, T2M_MAX,
   T2M_MIN trend / recent_extreme) over West Africa, the Sahel, North Africa and most land regions are
   established (IPCC AR6 WGI chapter 11 and Atlas). Region-wide warming is known_phenomenon. new_signal
   needs a specific extra feature (a dated step that an independent product does not show, a season or
   sub-region departing from the regional pattern, a decoupling between variables), stated in novelty_basis.
7. known_phenomenon is a success, not a failure: a blind rediscovery validates the harness.
